# NalaNiaga — CRM Freelancer & Agensi Kreatif

Sistem manajemen hubungan klien (*Customer Relationship Management*) dan pelacak pipeline deal modern berbasis PWA (*Progressive Web App*) untuk freelancer, studio desain, developer independen, dan agensi kreatif.

---

## 🌟 Fitur Utama

1. **Kanban Pipeline Prospek & Deal**:
   - 6 Tahap Konversi Terstruktur:
     1. **Prospek Baru (*Lead In*)**
     2. **Briefing & Diskusi (*Discovery*)**
     3. **Proposal Terkirim (*Proposal Sent*)**
     4. **Negosiasi Harga (*Negotiation*)**
     5. **Deal Aktif (*Won / On Going*)**
     6. **Selesai & Lunas (*Completed*)**
   - Pemindahan tahap deal satu ketukan (*One-click stage progression*).
   - Metrik otomatis: Total Potensi Pipeline, Proyek Aktif Berjalan, dan Realisasi Omzet.

2. **Database Klien & Kontak Terintegrasi**:
   - Penyimpanan data nama perusahaan/brand, kontak person (PIC), WhatsApp, email, dan kota domisili.
   - Segmentasi tier klien (VIP, Aktif, Calon Klien/Prospek).
   - Perhitungan otomatis riwayat proyek dan nilai transaksi sepanjang masa (*Lifetime Value / LTV*).
   - Tautan langsung **"Chat WhatsApp"** dengan pesan pembuka sopan profesional.
   - Fitur **Export Database Klien ke CSV**.

3. **Generator Invoice & Penawaran Proyek (Format A4)**:
   - Pembuatan tagihan formal dengan rincian item jasa (deskripsi, kuantitas, tarif satuan).
   - Kalkulasi otomatis Subtotal, PPN 11% (opsional), dan Grand Total.
   - Status tagihan (*Menunggu Pembayaran*, *Menunggu DP 50%*, *Lunas*).
   - Cetak langsung atau simpan ke file PDF format A4 resmi (`@media print` rapi dengan kop studio & kotak tanda tangan).
   - Tombol **"Kirim Invoice via WhatsApp"** dengan template tagihan siap kirim.

4. **Jadwal Follow-up & Aktivitas Prospek**:
   - Kalender pengingat follow-up klien (Chat WhatsApp, Meeting Zoom, Kirim Proposal, Penagihan DP).
   - Penandaan status selesai untuk menjaga *touchpoint* klien tetap tepat waktu.

5. **Statistik Omzet & Performa Agensi**:
   - Metrik eksekutif: Omzet Lunas, Pipeline Aktif, Win Rate Konversi, dan Total Klien.
   - Distribusi pendapatan berdasarkan kategori layanan (Web Development, UI/UX Design, Branding, dll).
   - Log aktivitas histori CRM real-time.

6. **PWA & Offline-First Ready**:
   - Penyimpanan lokal browser (*localStorage*) tanpa ketergantungan server database eksternal.
   - Dapat diinstal di desktop (Chrome/Edge/Mac) maupun smartphone/tablet (Android/iOS).

---

## 🚀 Panduan Penggunaan

- Buka tab **Pipeline Deals** untuk memantau alur proyek dan potensi omzet.
- Gunakan tombol **"Tambah Deal"** untuk mencatat inquiry baru dari calon klien.
- Gunakan tab **Invoice & Penawaran** untuk menerbitkan penagihan DP atau pelunasan dengan layout A4 siap cetak.
